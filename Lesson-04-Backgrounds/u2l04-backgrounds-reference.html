Backgrounds

Unit 2 · Lesson 4 · Reference

Every element is a box. You can paint it with a color, a gradient, a picture, or all three stacked in layers.

One color

background-color fills the whole box, including the padding.

.card { background-color: #2E1A47; }

A gradient

A gradient is an image, so it goes in background-image. Direction first (to right, 45deg, ...), then the colors.

.banner { background-image: linear-gradient(to right, #0B3D2E, #1F7A5C); }

A picture

The path in url() starts from the CSS file: here the picture is in an images folder next to style.css. cover fills the box and crops; position picks which part stays in view (center, top, bottom).

.banner { background-image: url("images/forest.jpg"); background-size: cover; background-position: top; }

Layers

Separate layers with commas. The first one listed is on top. background-color sits under all of them and shows if the image fails.

.banner { background-color: #0B3D2E; background-image: linear-gradient(rgba(0, 0, 0, 0.6), rgba(0, 0, 0, 0.6)), url("images/forest.jpg"); }

When it looks wrong

You seeCauseFix
The gradient never showsIt's in background-colorUse background-image
The image is missingWrong path or capitals (Forest.jpg)The path starts at style.css; match the name exactly
The image repeats in tilesNo background-sizeAdd cover as the background-size
The tint does nothingThe tint is listed after the imageList the tint first
No background at allMissing comma between layersPut a comma after each layer except the last

Words to know

background-colorone color under everything
linear-gradient()an image that fades from one color to another
url()points at an image file
coverfill the box, crop the extra
rgba()red, green, blue and opacity (0 to 1)
layerone image in a comma list; the first is on top
